INDOT IDM Roadway Calculators

Roadway design calculators built on the INDOT Indiana Design Manual (IDM): the 2013 IDM as revised by the Design Memoranda listed on each chapter. Every design value comes from the IDM chapter PDFs and is kept in separate data files tagged with the IDM section, figure and revision, so the values can be updated when the IDM changes.

Verify before use. These tools are design aids. Check every result against the current IDM and apply engineering judgment. Where the IDM itself has inconsistencies, the affected page notes them.

Not sure what to enter? Every input has an i button that explains it with a small sketch, and the Input Guide lists them all with IDM references, typical values and common mistakes.
